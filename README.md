# Angel · Lumi · Tron site taslağı

Mobil uyumlu, statik bir tanıtım sitesi. Angel, Lumi ve Tron’u ayrı ayrı tanıtır; ayrıca Pinterest uygulama başvurusu için temel proje sayfası olarak kullanılabilir.

## Yerelde görüntüleme

`index.html` dosyasını tarayıcıda aç. Site harici JavaScript veya derleme adımı gerektirmez.

## GitHub Pages ile yayınlama

1. İçeriği herkese açık yeni bir GitHub deposuna yükle.
2. Depoda **Settings → Pages** bölümünü aç.
3. Kaynak olarak **Deploy from a branch**, dal olarak `main`, klasör olarak `/ (root)` seçip kaydet.
4. GitHub’ın verdiği `https://kullaniciadi.github.io/depo-adi/` adresi ana sayfa olur; `privacy.html` gizlilik sayfasıdır.
5. Pinterest başvurusunun Website/App link alanında ana sayfa adresini kullan.

## Yayın öncesi tamamlanacaklar

- Gerçek site adı ve istenirse özel alan adı
- Bot davetleri ile destek topluluğu bağlantıları
- Gizlilik sayfasındaki iletişim ve veri silme yöntemi
- VDS’de kullanılan gerçek saklama/backup ayarlarıyla gizlilik metninin son kontrolü

Taslakta doğrulanmamış davet bağlantıları veya iletişim adresleri uydurulmamıştır. Yazı tipleri cihazdaki sistem yazı tiplerinden seçilir; harici font servisi çağrılmaz.
